# CRUD de Produtos - Console (C#)

Projeto em C# puro utilizando aplicação de console, com o objetivo de
praticar os fundamentos da linguagem e da Programação Orientada a Objetos.

## Conceitos aplicados
- Classes e objetos
- Encapsulamento
- Validação de domínio
- Lista de objetos (`List<T>`)
- CRUD em memória
- Estruturas de repetição e decisão

## Tecnologias
- .NET
- C#
- Aplicação Console
