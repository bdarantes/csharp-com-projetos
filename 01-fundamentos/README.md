# Fundamentos do C#

Nesta etapa estudo os conceitos iniciais da linguagem C#, entendendo
como programas são estruturados, como o código é executado e como
trabalhar com entrada, saída e tipos básicos.

## Conteúdo estudado
- Estrutura de um programa em C#
- Console.WriteLine e Console.ReadLine
- Variáveis e tipos primitivos
- Operadores
- Entrada e saída de dados
