# C# com Projetos 🚀

Repositório criado para documentar minha evolução no aprendizado da linguagem C#,
indo dos fundamentos até projetos práticos, seguindo boas práticas e organização.

## 🧠 Conteúdo
- Fundamentos da linguagem
- Lógica de programação
- Programação Orientada a Objetos
- Coleções e LINQ
- Tratamento de erros e arquivos
- Projetos em Console
- Introdução ao .NET e aplicações Web

## 🎯 Objetivo
Construir uma base sólida em C# e .NET, com foco em entendimento real da linguagem
e evolução contínua documentada via commits.
